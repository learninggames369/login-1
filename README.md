# Little Scholars — Login Page

A child-friendly student and parent login page.

## Features
- Student / Parent tab toggle
- Username or mobile + password, show/hide password
- Remember me, Forgot password
- Sign-up form (full name, username, class, parent mobile, password)
- GitHub sign-in / sign-up buttons
- Playful owl mascot with animated sky scene
- Fully responsive (desktop and phone)
- Light and dark theme

## Run locally
Open `index.html` in any modern browser.

## Preview with GitHub Pages
Enable Pages in repo Settings → Pages → Deploy from branch → `main` / `/ (root)`.
